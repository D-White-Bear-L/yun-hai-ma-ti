# 云海马体-记忆增强助理(Cloud Hippocampus - Memory Enhancement Assistant) 项目说明

## 项目简介

本项目开发一款智能穿戴设备（ai—glass）及配套软件，旨在实现【“记忆镜像化”】，以应对现代社会中日益增长的记忆管理需求。项目背景基于信息爆炸与人口老龄化的双重挑战，传统记忆辅助手段已无法满足多样化需求。项目目标是通过智能眼镜实时采集音视频数据，结合大模型技术实现长期记忆的有效存储、智能检索与个性化问答，为记忆障碍群体及普通用户提供任务提醒、物品寻找、精彩瞬间回顾等功能。项目采用云端协同架构，分为智能眼镜硬件、应用后台和前端聊天页面三大核心部分。技术创新点包括多模态检索架构、长视频摘要技术、大模型接口与接力机制以及云边端协同服务架构。功能创新涵盖被动式触发、隐私保护、室内目标辅助搜寻、任务智能提醒等。

## 功能特点

- OpenRouter 多模态大模型接力
- 多语言支持（中文、英文等）
- 自定义面具（Mask）功能
- 响应式设计，适配各种设备
- 四大核心功能：
    - 基于记忆溯源的情感陪聊
    - 物品智能搜寻
    - 代办事项管理
    - 云记忆展示（精彩瞬间）

## 环境要求

- Node.js 18.0 或更高版本
- npm 或 yarn 或 pnpm

## 部署指南

### 前端部署步骤

1. **环境准备**
   - 进入项目目录
   - 在终端运行 `yarn install` 安装依赖
   - 此步骤将下载并安装 yarn.lock 中定义的所有依赖包

2. **启动项目**
   - 运行 `yarn run dev` 启动开发服务器
   - 项目将在本地启动并可访问

### 手机环境需求

#### 设备兼容性

1. **主流手机型号**  
   应用兼容主流手机品牌及型号，如OPPO Find系列（Find N、Find N2、Find N3等）、OPPO Reno系列（Reno 10、Reno 11、Reno 12等）、华为P系列和Mate系列、小米MIX系列和Redmi系列等安卓机型，以及苹果iPhone系列（iPhone 8、iPhone X、iPhone 11、iPhone 12、iPhone 13、iPhone 14等），确保在这些设备上应用能够正常运行，无显示异常或功能故障。

2. **屏幕尺寸适配**  
   适配不同屏幕尺寸的移动设备，从较小的5英寸屏幕到较大的6.7英寸及以上屏幕，保证应用界面在各种尺寸下都能完整显示，元素布局合理，无错位或缺失。为保证软件的使用体验，移动端建议使用OPPO主流屏幕尺寸范围，即大致在6.43英寸到7.1英寸之间为佳。

3. **操作系统版本**  
   支持Android系统和iOS系统，具体版本需覆盖近3年内的主流版本，如iOS 14及以上、Android 8.0及以上，确保应用在这些系统版本上稳定运行，功能正常，且手机有足够内存运行。

#### 浏览器支持

1. **主流浏览器兼容**  
   确保应用在主流手机浏览器上能够良好运行，包括但不限于：Chrome浏览器、Edge浏览器、夸克浏览器。

2. **浏览器功能要求**  
   用户需确保浏览器支持JavaScript、CSS3、HTML5等基础网页技术，以保障应用的交互效果和功能实现。同时，建议用户开启浏览器的Cookies功能和授予麦克风权限，以便应用进行必要的用户会话管理和登录状态保持以及语音输入等功能的正常使用。

#### 网络环境

1. **网络连接要求**  
   应用支持Wi-Fi网络连接，同时兼容移动数据网络，包括4G和5G网络，确保用户在不同网络环境下都能流畅使用应用。在网络不稳定或信号较弱的情况下，应用具备相应的错误提示和重试机制，提升用户体验。

2. **最低网络带宽**  
   为保证应用的基本功能和数据加载速度，建议用户使用至少1Mbps的网络带宽。对于涉及高清图片、视频等多媒体内容加载的场景，更高的网络带宽将提供更佳的体验。

## 快速开始

### 安装依赖

或使用 yarn：

```bash
yarn install
```

### 本地开发

启动开发服务器：

```bash
yarn run dev
```

访问 [http://localhost:3000](http://localhost:3000) 查看应用。

### 构建生产版本

```bash
yarn build
```

或者

```bash
yarn install
yarn build
PORT=8081 yarn start
```
